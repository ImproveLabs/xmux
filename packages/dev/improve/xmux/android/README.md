# Android libraries

Reusable Android modules for bridge connections (`xmux-client`) and Quest integration (`xmux-spatial`).
`xmux-core` is a convenience bundle for the terminal primitives and views; `xmux-demo-content`
supplies internal demo data.
Independent UI components and the `xmux-compose` convenience bundle live in [`../components/`](../components/).
Terminal data, layout, font, and keyboard libraries live in [`../lib/`](../lib/).
Generated protocol types (`xmux-proto`) live in
[`../schema/proto/android/`](../schema/proto/android/).
